Entry for the [make.fun](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc) competition **"Monday Morning Punchlines"**.

`main.py` (pure Python 3 stdlib) copies the one-line joke in `entry.txt` to `/output/entry.txt`.

> Monday clocked in early, made the coffee, and still got blamed for everything — honestly, it's the most reliable employee I have.

The line is 129 characters (UTF-8, within the 1–200 limit). Instead of complaining about Monday, it flips the cliché: Monday is the eager early-bird coworker who does everything right and still takes the blame.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
